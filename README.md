# CodeNova
An interactive learning platform that teaches computer science through step-by-step visual explanations.

Live demo: https://code-nova-ashen.vercel.app

## Features
- Data Structures and Algorithms visualizations
- OOP and Cryptography modules
- Code sandbox
- Level-based quizzes, 1v1 duels and hosted competitions
- XP, badges and daily streaks

## Tech Stack
React, Vite, Tailwind CSS, Node.js, Express, MongoDB, Socket.io

## How to run
Backend:
cd backend
npm install
npm run dev

Frontend:
cd frontend
npm install
npm run dev

Create a .env file inside backend with PORT, JWT_SECRET and FRONTEND_URL.
